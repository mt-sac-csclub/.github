## How we build

Club projects use a simple, reviewable workflow:

1. Develop and validate changes on `dev`.
2. Open a pull request from `dev` to `main`.
3. Merge only after CI passes and review feedback is addressed.

See our [contribution guide](../CONTRIBUTING.md) for the shared project standards.
